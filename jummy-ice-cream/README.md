# Jummy Ice Cream Website

A responsive, front-end recreation of the supplied Jummy Ice Cream Figma screenshot using HTML, CSS, JavaScript and Bootstrap 5.

## Project structure
- `index.html` — page structure and content
- `css/style.css` — layout, colors, responsive styling and decorative drip edges
- `js/script.js` — product selection toast and mobile navigation behavior
- `assets/images/` — generated ice-cream photos used by the page

## Run locally
1. Extract the ZIP file.
2. Open the `jummy-ice-cream` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Internet access is needed for Bootstrap CDN, Google Fonts and the embedded OpenStreetMap map.

## Notes
- The layout is designed to closely follow the provided reference: cream navigation, drip decoration, hero, about section, four flavor cards, social links and map.
- The ice-cream images are newly generated visual assets, not original Figma exports.
- Facebook and Instagram buttons use the profile links supplied. Phone numbers are clickable.
- This is a front-end demo; it does not process or store real orders.
